# Security policy

NeuroMind Atlas supports the latest version published from the `main` branch.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository Security tab when it is available. Do not include mental-health information, secrets, or working exploit details in a public issue. If private reporting is unavailable, open a minimal public issue requesting a private contact channel without disclosing the vulnerability.

Please include the affected URL or file, expected and observed behavior, reproducible steps, and an impact assessment. Reports are evaluated before publication.

General content corrections that do not involve security can follow `CONTRIBUTING.md`.
